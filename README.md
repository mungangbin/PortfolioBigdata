# 문강빈 · 데이터 분석 포트폴리오

> 데이터에서 문제를 찾고, 그 결과를 사용자가 바로 쓸 수 있는 서비스로 연결하는 데이터 분석가를 준비하고 있습니다 · 전주대학교 인공지능학과 3학년

<br>

## 1. 소개

안녕하세요, 데이터 분석과 데이터 기반 서비스 기획에 관심이 있는 문강빈입니다.

인공지능을 전공하면서 모델을 만드는 것만큼, 데이터를 정리하고 그 안에서 의미 있는 차이를 찾아내는 과정이 중요하다는 것을 배웠습니다.
그래서 분석을 숫자로 끝내지 않고, "이 결과를 본 사람이 무엇을 하면 되는가"까지 이어지는 결과물을 만드는 것을 목표로 공부하고 있습니다.

| 항목 | 내용 |
|---|---|
| 소속 | 전주대학교 인공지능학과 3학년 |
| 관심 분야 | 데이터 분석, 데이터 기반 서비스 기획 |
| 강점 | 흩어진 공공데이터를 분석 가능한 형태로 정리하고, 결과를 사용자 화면까지 연결 |
| 활동 | 2026 전주대 AI 커리어 점프업 캠프 3조 (빅데이터 분석) |

## 3. 대표 프로젝트

### 01. 꽃가루 위험 예측 서비스

> 공공데이터로 꽃가루 위험 패턴을 분석하고, 알레르기 민감자를 위한 예측 웹 서비스로 만든 개인 프로젝트 · 2025.05 ~ 06

| 항목 | 내용 |
|---|---|
| 문제 | 꽃가루 정보가 숫자 지수로만 제공되어, 민감자가 외출이나 마스크 착용을 판단하기 어려움 |
| 한 일 | 공공데이터 13개 파일 수집 · 전처리, 다섯 가지 분석, 마르코프 체인 예측, Streamlit 서비스 구현 |
| 결과 | 4,160행 분석, 보통 이상 위험일 41% 확인, 요일별 위험도 약 2.6배 차이 발견 |
| 기술 | Python, pandas, matplotlib, seaborn, Streamlit |

자세한 내용: [프로젝트 README 보기](01_pollen-forecast)
